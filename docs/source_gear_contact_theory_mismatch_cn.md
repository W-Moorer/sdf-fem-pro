# 齿轮接触应力/应变误差理论定位

## 当前结论

当前齿轮算例的位移曲线已经基本对齐，但应力/应变曲线仍显著偏高。问题不是单纯的应力云图后处理，也不是 SDF 查询精度不足，而是 SFC 当前接触约束的几何激活口径与 Abaqus/Standard 的 surface-to-surface contact element 口径不一致。

0.0004 s 末帧的关键诊断如下：

- Abaqus ODB contact field：active contact node = 44，max CPRESS = 4.46268e5，max COPEN penetration = 9.72946e-5。
- SFC secondary-line 路径修复前：active contact node = 744，max contact pressure = 1.72479e7。
- 加入 closest-feature release guard 后：active contact node = 564，max contact pressure = 1.69505e7。
- 将 Abaqus 末帧真实节点坐标直接送入 SFC 接触几何，SFC 仍得到 min gap 约 -3.58e-3。

因此，剩余误差不是 SFC 求解轨迹把结构推错后才出现的，而是在同一 Abaqus 几何状态下，SFC 接触几何本身就生成了 Abaqus 不会生成的深 overclosure。

## 已修复的问题

### 1. Secondary-line 投影会在最近特征张开时制造虚假压缩

原 C++ batch kernel 只要 slave normal 射线命中某个 master 三角形，就直接接受该 line gap。诊断显示，在 0.0004 s checkpoint 中：

- secondary-line active samples = 1770；
- 其中 720 个样本的 closest-feature gap 实际为正；
- 这些样本会产生最高约 1.73e7 的虚假 contact pressure。

已修复：

- Python reference path 和 C++ batch path 都增加 release guard；
- 若 line gap 为负，但 closest-feature clearance 为正，则不允许该 line hit 产生压缩接触；
- 新增回归测试覆盖 Python 和 C++ 两条路径。

修复后：

- line-active but closest-open 样本从 720 降为 0；
- 位移误差保持在约 2% 内；
- 但应力/应变仍未进入 10% 内，说明还有更深层理论口径差异。

## 仍存在的理论差异

### 2. Abaqus 初始接触元素没有惩罚初始几何 overclosure

Abaqus 初始帧导出结果：

- active contact node = 0；
- max CPRESS = 0；
- min COPEN = 0。

但 SFC 在同一初始几何上用当前 secondary-line 接触几何会得到非零负 gap。Abaqus 的 `.dat` 文件显示：

- NUMBER OF INTERNAL ELEMENTS GENERATED FOR CONTACT = 34680；
- NUMBER OF INTERNAL NODES GENERATED BY THE PROGRAM = 69360。

这说明 Abaqus/Standard 为 surface-to-surface contact 生成了内部 contact elements，并在初始状态建立了自己的 contact clearance / tracking 语义。SFC 目前直接把原始几何 signed gap 送入罚函数，没有等价实现这层 contact element 初始化。

### 3. SFC 当前每步全局重搜 master face，缺少 Abaqus-style contact tracking

SFC 当前在每个接触查询中从大 contact patch 里重新搜索任意 master face。齿轮齿面存在多个邻近斜面时，slave normal 射线可能跳到远处齿面，形成 Abaqus 不会激活的深 overclosure。

离线诊断显示：

- 深 overclosure 样本的 line-hit master face 与 closest-feature face 大多不一致；
- shallow overclosure 样本多数与 closest-feature face 一致；
- 这说明错误主要来自错误 contact patch/face tracking，而不是单个三角形投影公式精度。

### 4. `secondary_average` 仍不等价于 Abaqus constraint-region normal

已经把 secondary-line 的法向从 faceted face normal 改为 slave surface nodal averaged normal，但单独这一项不足以消除误差。原因是 Abaqus 的 surface-to-surface 接触不仅平均法向，还包含 contact element、constraint averaging、contact status tracking 和初始 clearance 语义。

## 下一步通用修复顺序

### 已推进：secondary contact tracking tube

`secondary_average + secondary_line` 路径已经从 closest-feature 的保守 feature-size radius 分离出来。closest-feature SDF 查询仍使用 surface feature size 保护精确最近特征；Abaqus-style secondary surface contact 使用 initial-clearance / overclosure tolerance 定义的 contact tracking tube。

0.0004 s 窗口验证中，显式使用 1.0e-4 tracking tube 后：

- final displacement relative error = 3.36%；
- final global p95 von Mises relative error = 6.23%；
- final global p95 equivalent strain relative error = 6.23%；
- final max node-averaged von Mises relative error = 7.72%；
- final min gap 从毫米级过闭合降至约 -1.23e-4。

但 0.00020--0.00032 s 中段 p95 stress 仍有 30%--52% 偏差。Abaqus contact field 显示该时间段 CPRESS/active nodes 继续升高，而固定 tracking tube 的 SFC 过早降低接触压力。因此下一步不是再放大全局半径，而是实现 contact patch tracking / adjacency migration：只允许约束沿相邻 master patch 滑移迁移，避免远处齿面跳转，同时不因固定小半径丢失真实滑移接触。

1. 实现 Abaqus-style contact element 初始化：
   - 为每个 slave surface constraint region 建立初始 master patch / 初始 clearance；
   - 初始帧不因原始几何 overclosure 自动产生 CPRESS；
   - 输出 initial contact adjustment / clearance 诊断。

2. 实现 contact tracking / active patch cache：
   - 每个 slave constraint region 持有 master patch 候选组；
   - 每步只 refit 当前 patch AABB，不允许无约束跳到远处齿面；
   - 允许通过邻接 patch 进行通用滑移迁移，而不是硬编码齿轮算例。

3. 将 pressure-overclosure law 作用在 Abaqus-style effective overclosure 上：
   - `p = k * max(-g_eff, 0)`；
   - `g_eff` 来自 tracked contact element clearance，而不是裸 secondary-line signed gap。

4. 重新跑 0.0004 s、10 步、全流程齿轮对比：
   - 先要求 Abaqus 末帧几何喂入 SFC contact geometry 时，CPRESS/COPEN 量级接近 Abaqus；
   - 再跑 SFC 自己求解轨迹；
   - 最后比较位移、应力、应变和效率。

## 当前不能下的结论

当前不能把齿轮应力/应变误差归因于材料模型或应力后处理。位移对齐但应力/应变不对，是因为接触压力分布不对；接触压力分布不对，是因为接触约束激活语义尚未对齐 Abaqus/Standard 的 surface-to-surface contact element 理论。
