# Phase-10 Existing Experiment Coverage Analysis

This document checks whether the proposed FEM-SDF contact experiment layers already exist in the repository and whether each layer can support the current true dynamic narrow-band SDF field paper.

## Key Criterion

For main-paper evidence under the current method, a contact experiment should use:

```text
current FEM boundary
-> DynamicNarrowBandSDF.build(...)
-> interpolation-only query
-> field_contact gap/Jacobian/force path
```

Experiments that use `dynamic_surface_sdf`, direct closest-point projection, or external deformed-state replay may be useful as migration sources or supplementary evidence, but they are not yet direct true-field solver evidence.

## Directly Ready Evidence

The following is now aligned with the current paper method:

- `DynamicNarrowBandSDF` construction and interpolation queries.
- Phi-grid and payload-grid evidence.
- Scalar derivative consistency.
- Slave/master field-contact Jacobian finite-difference checks.
- Field penalty force/action-reaction checks.
- Field update/query timing and measured \(Q^\ast\).
- 3D visual audit generated by `validation/run_external_visual_validation.py`.
- Native static/dynamic TET4 and HEX8 plane-contact checks generated by `validation/run_phase10_true_field_contact_cases.py`.
- C3D8 trajectory replay and Phase-9 HEX8/C3D8 contact adapters now query `DynamicNarrowBandSDF` through `field_contact_constraint_from_sample(...)` instead of directly calling `dynamic_surface_sdf(...)`.
- Solver-level contact-dominated timing generated by `validation/run_true_field_solver_timing.py`, including FEM assembly, exact required-node field update, contact force, and static solve or dynamic update.

This supports the SDF field and field-contact operator claims.

## Existing Evidence That Needs Repositioning

Several historical scripts still contain useful supplementary material, but they must remain scoped carefully:

- `validation/run_contact_query_equivalence.py`: useful controlled plane-contact case, but not a true narrow-band field solve.
- `validation/run_deforming_master_sdf_reference.py`: useful prescribed deformation reference, but not a coupled solver-level case.
- `validation/run_calculix_contactenergy_replay.py`: C3D8 static external reference now uses true-field queries, but remains replay-oriented supplementary evidence.
- `validation/run_c3d8_contact_trajectory_validation.py`: dynamic C3D8 replay now uses true-field contact queries, but CalculiX or synthetic data still supply the trajectory.
- `validation/run_phase9_full_contact_validation.py`: rich case matrix now uses a field-backed HEX8 contact adapter, but nonlinear rows remain supplementary claim-gated evidence.
- `validation/run_geometric_nonlinear_contact_validation.py`: useful nonlinear diagnostic suite, but out of current main-method scope.

These are migration sources, not final proof of the current true-field method.

## Missing Main-Paper Experiments

The repository now has the first clean solver-level experiment set for:

1. Static linear TET4 contact solved natively with `DynamicNarrowBandSDF + field_contact`.
2. Static linear HEX8 contact solved natively with `DynamicNarrowBandSDF + field_contact`.
3. Dynamic linear TET4 contact history solved natively with the true field path.
4. Dynamic linear HEX8 contact history solved natively with the true field path.

The total-step timing item is now covered for linear TET4/HEX8 contact-dominated workloads. The remaining missing item for a broader claim is deformable-master coverage beyond the analytic plane and any main-text nonlinear claim. The current supported claim is:

```text
FEM-SDF accurately computes linear TET4/HEX8 flexible-body contact and is faster in contact-dominated regimes after the measured Q*.
```

## Migration Priority

1. Expand native true-field cases beyond the analytic rigid plane to deformable master surfaces.
2. Report displacement, stress, strain, pressure, gap, penetration, reaction, energy, active set, and total-step timing in one paper-facing table.
3. Keep nonlinear TET4/HEX8 evidence as supplementary until nonlinear solver and true-field contact gates are separately validated.

## Bottom Line

The first migration layer is now in place: native TET4/HEX8 static and dynamic linear contact checks use the true dynamic narrow-band SDF field path, the C3D8 trajectory/Phase-9 adapters no longer directly call the old projection-query API, and contact-dominated total-step timing now supports the scoped acceleration claim after measured \(Q^\ast\). The exact required-node field update lowers default-scale \(Q^\ast\) from about `5567` to `849` while preserving roundoff-level gap and force agreement. The next evidence gap is broader deformable-master coverage; nonlinear FEM remains supplementary unless separately implemented and validated.
